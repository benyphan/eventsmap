# EventsMap — мобильное приложение (React Native / Expo)

## Что нужно перед запуском

1. Node.js уже установлен (проверял `node --version`) ✅
2. Приложение **Expo Go** на телефоне (Google Play)
3. Backend уже должен быть запущен на компьютере (`uvicorn app.main:app --reload --port 8020`)

## Установка

1. Распакуй архив, открой папку `mobile-app` в терминале.
2. Установи зависимости:
   ```
   npm install
   ```
   (первая установка может занять пару минут)

3. **ВАЖНО:** узнай IP-адрес своего компьютера в локальной сети:
   ```
   ipconfig
   ```
   Найди строку "IPv4-адрес" (обычно `192.168.х.х`), например `192.168.1.42`.

4. Открой файл `src/api/client.js` и замени строку:
   ```js
   const BASE_URL = "http://192.168.1.100:8020";
   ```
   на свой реальный IP, например:
   ```js
   const BASE_URL = "http://192.168.1.42:8020";
   ```
   Это нужно, потому что телефон и компьютер — разные устройства в сети, `localhost` с телефона не сработает.

5. Убедись, что телефон и компьютер подключены к **одному и тому же Wi-Fi**.

6. Запусти проект:
   ```
   npx expo start
   ```
   Появится QR-код в терминале и в браузере.

7. Открой приложение **Expo Go** на телефоне, отсканируй QR-код (на Android — прямо из самого приложения Expo Go, кнопка "Scan QR code").

8. Приложение загрузится на телефон — можно регистрироваться, заходить, смотреть карту и ленту событий.

## Структура проекта

```
mobile-app/
  App.js                    — навигация (стек логина + нижние вкладки)
  src/
    api/client.js            — обращения к backend (axios)
    screens/
      LoginScreen.js          — вход
      RegisterScreen.js        — регистрация
      MapScreen.js              — карта (Leaflet внутри WebView)
      FeedScreen.js              — лента мероприятий (карточки)
      ProfileScreen.js            — профиль
      SettingsScreen.js            — настройки
```

## Частые проблемы

- **"Network Error" при входе/регистрации** → скорее всего неправильный IP в `client.js`, или телефон не в той же Wi-Fi сети, или backend не запущен.
- **Windows Firewall блокирует подключение** → при первом запуске backend Windows может спросить разрешение — обязательно разреши доступ для приватных сетей.
- **QR-код не сканируется** → убедись что используешь именно Expo Go, а не обычную камеру.
